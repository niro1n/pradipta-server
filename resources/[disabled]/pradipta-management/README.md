# PRADIPTA - management
- Manage employees online or offline!
- Access a personal boss level stash!
- Allows for multiple boss menu locations!

## Dependencies
- [pradipta-core](https://github.com/pradiptacore-framework/pradipta-core)
- [pradipta-smallresources](https://github.com/pradiptacore-framework/pradipta-smallresources) (For the Logs)
- [pradipta-input](https://github.com/pradiptacore-framework/pradipta-input)
- [pradipta-menu](https://github.com/pradiptacore-framework/pradipta-menu)
- [pradipta-inventory](https://github.com/pradiptacore-framework/pradipta-inventory)
- [pradipta-clothing](https://github.com/pradiptacore-framework/pradipta-clothing)
